## Exam Overview

The **Databricks Certified Generative AI Engineer Associate** exam validates your ability to design, build, deploy, evaluate, and govern Large Language Model (LLM)-enabled solutions and Retrieval-Augmented Generation (RAG) applications using the Databricks Data Intelligence Platform.

| Parameter | Exam Specification |
| --- | --- |
| **Exam Name** | Databricks Certified Generative AI Engineer Associate |
| **Exam Code** | N/A (Databricks lists this exam directly by name) |
| **Total Questions** | 45 scored multiple-choice questions |
| **Time Allowed** | 90 minutes |
| **Passing Score** | ~70% |
| **Delivery Method** | Proctored Online or Test Center via Webassessor |
| **Validity** | 2 Years |
| **Language & SDKs** | Python primary (SQL for non-ML data operations) |

## Who Should Take It

This certification is designed for AI engineers, data engineers, machine learning engineers, solutions architects, and software developers building production GenAI solutions.

**Recommended Prerequisites:**
- At least 6 months of hands-on experience building GenAI workflows or RAG applications on Databricks.
- Strong proficiency in Python development, prompt design, and LLM integration frameworks (LangChain, LlamaIndex, PyFunc).
- Familiarity with core Databricks components: Delta Lake, Unity Catalog, Databricks Vector Search, MLflow, and Foundation Model Serving.
